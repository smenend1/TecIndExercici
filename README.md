# Tecnologia Industrial Exercicis Plus

PWA educativa en català per practicar exercicis tipus PAU de Tecnologia Industrial, Tecnologia i Enginyeria i blocs afins d'Electrotècnia.

## Inclou
- Mode PAU amb test autocorregible.
- Exercicis guiats pas a pas.
- Calculadores tècniques.
- Pràctica autocorregible.
- Formulari.
- Historial amb localStorage.
- Manifest i Service Worker.
- Preparada per GitHub Pages.

## Publicació a GitHub Pages
Puja tots els fitxers a la branca principal del repositori i activa GitHub Pages des de Settings > Pages.

## Nota
No utilitza llibreries externes. Els exercicis són plantilles didàctiques inspirades en patrons PAU i ampliables.
