- Selector Alumne / Docent.
- Resolució per passos amb pistes, comprovació i solució gradual.
- Fitxa imprimible per a l'alumne amb espais de resposta.

## v10 · Buidatge total

Aquesta versió mostra 52 fitxes generades a partir dels 5 PDF únics pujats: Tecnologia i enginyeria 2025, Electrotècnia 2023, Tecnologia i enginyeria 2024, Tecnologia industrial 2022 i Tecnologia industrial 2021. Les fitxes incorporen enunciat complet textual, apartats detectats, dades principals, fórmules, pistes, errors habituals i mode alumne/docent. Els exercicis amb figures queden marcats com a fitxes guiades; les imatges es poden integrar en una versió posterior.
